> **기업의 ESG 성과와 임직원 복지를 동시에 해결하는 혁신적인 해양환경 보호 프로젝트**

## 🎯 프로젝트 개요

**MOBA**는 기업 임직원이 스쿠버·프리다이빙 국제 자격증을 취득하고, 정기적인 수중 정화활동(플로빙)을 통해 바다를 깨끗하게 만드는 **통합 ESG 실행 프로그램**입니다.

### 💡 핵심 아이디어

> **"교육 → 수중 정화 → 데이터 업로드 → ESG 보고"**

환경 보호를 위해 누군가 희생하는 것이 아니라, **모두가 혜택을 받으며 바다를 살리는 선순환**을 만듭니다.

---

## 🌍 해양오염의 현실

### 📊 글로벌 현황
- **매년 480만~1,270만 톤**의 플라스틱이 바다로 유입
- **북태평양 거대 쓰레기 지대**: 남한 면적의 **16배** (180만㎢)
- **한국 연안**: 연간 **14만~17만 톤** 발생, **절반 이상 미수거**

### 💰 경제적 피해
- **폐그물로 인한 피해**: 연간 **3,787억 원**
- **집중호우 시 관광 피해**: 약 **300억 원**

---

## 🏢 기업에게 주는 가치

### 🌱 **환경(E)**: 검증 가능한 ESG 데이터
- **PADI AWARE Foundation** 글로벌 해양 데이터베이스 등재
- **GRI 306, ISO 14001, SDG 14** 완벽 부합
- **"폐플라스틱 600kg 수거, 임직원 100명 참여, 봉사 800시간"** 구체적 수치로 증명

### 👥 **사회(S)**: 임직원 복지와 지역사회 공헌
- **평생 레저 자격증** (Open Water/Freediver) 회사 지원
- **전문 봉사의 보람**과 개인 성장
- **지역 예술가와 협력**한 업사이클링 프로젝트

### 🏛️ **거버넌스(G)**: 투명한 운영과 국제 인증
- **그린워싱 제로**: UNEP 연계 국제기구 인증
- **조작 불가능한 투명한 시스템**
- **브랜드 신뢰도 상승**과 규제 선제 대응

## 🎯 프로그램 구조

### 📚 **1단계: 교육 및 자격 취득**
- 스쿠버/프리다이빙 국제 자격증 취득 지원
- Dive Against Debris® 전문 교육
- 안전 장비 및 수거 도구 지급

### 🤿 **2단계: 수중 정화 활동**
- **연 4회** (분기 1회) 정기 활동
- **수심 2-10m** 연안에서 안전한 수거
- **전문 인솔자** 주관 하에 2-3인 1조 운영

### 📊 **3단계: 데이터 수집 및 보고**
- **GPS 좌표, 무게, 품목** 정밀 기록
- **PADI AWARE Foundation** 글로벌 DB 업로드
- **연말 ESG 보고서** 반영

## 🎨 시각화 프로젝트

### 🎭 **"수거 → 협력 → 시각화 → 공유"**

수거한 해양폐기물을 지역 예술가, 청소년, 어민과 협력하여:
- **벽화 및 조형물** 제작
- **어선 페인팅** 및 커뮤니티 아트
- **공공공간 창작**을 통한 사회적 가치 확산

## 🛠️ 빠른 시작

### 📋 **사전 요구사항**
- Node.js 18.0.0 이상
- Docker 24.0.0 이상 (선택사항)

### 🚀 **로컬 개발**
```bash
# 저장소 클론
git clone https://github.com/ChangooLee/moba.git
cd moba

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
# 브라우저에서 http://localhost:5173 접속
```

### 🐳 **Docker 실행**
```bash
# Docker Compose로 실행
docker-compose up --build -d

# 브라우저에서 http://localhost:8084 접속
```

## 🎯 비전과 미션

### 🎯 **비전**

- **혁신**: 혁신적인 기술과 방법론으로 해양 보호 접근
